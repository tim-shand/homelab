# 🔑 SSH Keys

This directory is used to contain both **PRIVATE** and **PUBLIC** key files. 

- The SSH key files in this directory are generated by Terraform during deployment.
- SSH public key values are added to the VM using the cloud-init process.
- Ensure the key files are backed up or moved to the required destination once created.

> [!WARNING]
> During a Terraform `DESTROY` deployment, the SSH key files will be **removed** from this directory.
